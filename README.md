## 🔧 Workflow

1. **Write your section** in `/sections/` as a `.md` file
2. **Add your references** to `/references/references.bib`
3. **Commit and push** your changes with a clear message
4. **Do NOT edit** `paper/main.docx` alone — do it together

### Git Commit Convention
```
[section] brief description
e.g.:
[intro] add problem statement
[refs] add 5 new PQC papers
[forensics] complete section 5 draft
```
